**2. 도구 활용**

도서 검색, 대출 정보 확인, 이용자 회신 등의 기능을 도구로 구현한다.

도구를 통해 확인하지 않은 정보를 임의로 만들어 안내하지 않는다.



**3. Context 및 미들웨어 활용**

사서의 이름과 역할을 Runtime Context에 저장한다.

미들웨어를 통해 해당 정보가 모델 입력에 반영되도록 구현한다.



**4. 가드레일 적용**

도서관 업무와 무관한 요청은 적절히 거절한다.

다른 이용자의 대출 정보처럼 공개해서는 안 되는 정보에 대한 요청을 차단한다.



**5. 기억 기능 활용**

단기 기억을 활용해 대화 내용을 유지한다.

장기 기억을 활용해 이용자 선호 등의 정보를 저장하고, 필요할 때 활용한다.
